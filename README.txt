食事ログ PWA 公開用ファイル一式
- index.html / manifest.webmanifest / sw.js / icons/ をすべて同じ場所(同じフォルダ)に置いて公開してください。
- HTTPS で配信される無料ホスティング(GitHub Pages / Cloudflare Pages / Netlify など)で動きます。
- 公開後、スマホのブラウザでURLを開き「ホーム画面に追加」するとアプリとして起動できます。
- アプリを更新した場合は、sw.js の V='dietlog-v2' の数字を上げて再アップロードすると、確実に入れ替わります。
